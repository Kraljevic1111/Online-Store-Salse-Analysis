# Online-Store-Salse-Analysis
Analyzing data from online store-e-commerce

This project analyzes sales data using Python, pandas, and matplotlib/seaborn.

## Features
- Revenue calculation
- Revenue analysis by category and month
- Top customer identification
- Datetime processing
- Data visualization with bar and line charts

## Technologies
- Python
- pandas
- matplotlib
- seaborn

## Skills Demonstrated
- Data analysis
- GroupBy operations
- Datetime handling
- Data visualization
- Business insight generation
